B.O.O.M
Clear the bio-nuclear research facility overtaken by robot scientists. Gun them down before they launch a ballistic missile that will exterminate all of humanity.

In this project we had to implement physics using a physics library. I chose NVIDIA PhysX for its efficiency and robust simulation features. It let me handle collisions, gravity and object interactions smoothly, which made the gameplay feel more realistic and responsive.

At a glance

  • Team: 15
  • Reference: DOOM
  • Duration: 16 weeks at 50% pace
  • My contributions: the physics engine using PhysX, and animations

Physics engine using PhysX

This took up most of my time on the project. I wanted the engine to be easy for the rest of the team to use, so they had to do as little work as possible on their own.

The first iteration already supported creating and deleting multiple actors at runtime, with a working cleanup process for proper memory management. It was a crucial milestone in making the game world more dynamic and interactive.

Reworking the physics engine

As I learned more about PhysX and how it works, I reworked the engine twice to improve performance. The first rework optimized physics calculations and collision detection. The second improved scalability and made it interact more smoothly with other game systems. Each iteration made the engine more efficient and responsive.

I later brought this physics engine into my own engine for my FABRIK specialization.
