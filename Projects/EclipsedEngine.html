Eclipsed Engine
Eclipsed Engine is a custom 2D game engine and editor written in C++. I've been building it with one other developer since August 2025, and we're using it to make our co-op game, code-named Project Nova.

I've written about three quarters of the engine's current codebase. Below are the systems I own. The source is on GitHub.

Other Systems I Built

Asset Pipeline
GUID-based meta files and a typed importer for textures, materials, shaders, fonts, audio, scenes and prefabs. Reference-counted cache with a deferred deletion queue, hot-reload from a file watcher, and cooking of all assets into one binary bundle for game builds.
C++Binary Formats
Editor
Inspector with reflection-driven field drawers, asset browser with drag and drop, and saved dockable layouts. Play mode with pause, step and scene snapshots, a console that separates engine and game logs, and settings panels.
ImGuiTools
2D Lighting & Shadows
Point, spot, ambient and directional lights. Lights render to their own frame buffer and are composited with a separate shadow pass.
OpenGLGLSL
Audio
A plugin-based audio backend with an FMOD implementation. FMOD Studio banks and events, and audio emitters with volume and pan that pause and resume with play mode.
FMODC++
Plugin-Based Backends
The renderer and audio backends are separate DLLs loaded at startup, so the engine core doesn't depend on OpenGL or FMOD directly.
C++Architecture
Input System
Named actions and axes mapped to keys, saved to and loaded from file, with an editor panel for rebinding keys and debugging input.
C++GLFW
Profiler
Scoped timing that builds a call tree for each engine phase, shown live in the editor with entries over the frame budget highlighted.
C++Performance
Core Library
File system utilities (file watcher, directory tree, memory-mapped files), an arena allocator, timers, process launching, logging, a settings registry and an event system.
C++Win32
